# 五路评分 v2：数据、规则与验证

模型版本 `arena-role-evidence-v2`，更新于 2026-10-16。用于朋友之间的十人分队。其权重和0–100映射为本应用设计，并非腾讯公开的隐藏匹配分公式。

## 为何更换 v1

旧版给五路相同的段位基础，仅以 `(英雄收缩胜率-50%) × 14` 作微调，没有使用战力、巅峰记录和近季英雄。当前QQ档案因此五路只有66.1～66.5。v2明确区分账号基础与位置能力，再把位置分交给现有分队算法。

## 核对的游戏机制与数据边界

1. [腾讯官网：2025-05-29 体验服更新公告](https://pvp.qq.com/web201706/newsdetail.shtml?tid=774295)。官网正文由[官方新闻接口](https://apps.game.qq.com/wmp/v3.1/public/searchNews.php?p0=18&source=web_pc&id=774295)加载，已读取正文。该公告描述战力与表现、段位和巅峰分路系数的关联，以及周回收和赛季继承。这说明战力和段位、巅峰分高度相关，也会随活跃和赛季变化。它是2025年的体验服公告，不当作2026当前正式服精确配置；没有硬编码其中的场数、系数、上限作为本模型的官方标准。
2. [腾讯官网英雄目录](https://pvp.qq.com/web201605/js/herolist.json)。本项目保存133项目录及roles映射，职业hero_type不等同于分路。目录推荐位置不能证明个人使用英雄时的实际位置。
3. 用户授权返回的实际档案：累计英雄含games/wins/winRate/power/proficiency；赛季有rankStats/peakStats及部分常用英雄；最近一页对局有模式和日期。目前没有完整个人五路实际场次、对手强度、单双排拆分、五路巅峰积分、完整逐场时间序列及每个英雄历史最高战力。因此不虚构这些字段，不用全服百分位作标签。

据此，v2限制战力重复加分、参考近季而不是远古最高分、区分默认巅峰分与实际参赛、降低多位置映射确定性。具体映射与权重是本应用推断，以下均为模型参数。

## 公式

`位置分 = clamp(0.40A + 0.25H + 0.20E + 0.15D + P + S + M, 5, 95)`。

| 项 | 含义 | 计算 |
| --- | --- | --- |
| A | 账号竞技水平 | 当前段位指数80%与近三季加权指数20%平滑；有实际巅峰场次时，以最多35%的可靠性权重混合巅峰指数。近30天竞技胜负作最多±1.5修正 |
| H | 主力英雄表现 | 按近期可见使用50%、生涯练习30%、战力20%确定主力前3；排序不采用胜率。前3按0.5/0.3/0.2混合后验胜率，映射 `50 + 160×(胜率-0.5)`，限10～90 |
| E | 分路熟练度 | 练习场次以180场为指数衰减尺度，结合使用占比；可用时10%参考接口熟练度等级。场次上升有递减收益 |
| D | 英雄池深度 | 每英雄以50场为熟练度饱和尺度，多位置均分，折算熟练英雄数r，`100×(1-exp(-r/2.5))` |
| P | 当前战力加成 | 每路当前战力最高的3个已使用英雄，经分段函数和0.5/0.3/0.2权重混合，最多10分；无当前战力时为0加成 |
| S | 个人分路专精 | 生涯使用占比50%、近三季可见英雄场次占比35%、当前战力分布15%；缺失来源重新归一。以五路均衡20%为中性，`clamp(12×ln((占比+0.04)/0.24),-14,10)` |
| M | 本人明确校正 | -15～15；偏好/避开只改分队适配，不增加观测实力 |

### 账号基础

王者段起点62，每星0.2，最多150星；无星数时根据段位称号给下限先验。王者以下依青铜、白银、黄金、铂金、钻石、星耀映射16/23/31/39/47/55，并考虑小段位和星数。此数列为比较尺度，不宣称每一级真实实力等距。

巅峰指数锚点：1200→50、1500→64、1800→77、2100→87、2400→94、2700→98，分段线性插值。仅近三季且`peakStats.games>0`的记录有效。场次最多取100作权重，可靠性`加权场次/(加权场次+30)`。有日期时额外降权；不同赛季按编号距离`0.6^距离`下降。不使用生涯最高巅峰抬高所有分路。

### 英雄胜率与重叠样本

- 生涯英雄样本单英雄最多180，因模式未知再乘0.55；展示胜率推导的胜场再乘0.7。
- 近三季单英雄每模式最多80场，按赛季距离和日期降权。列表是部分常用英雄，未出现不等同于没玩过。
- 最近30天最多30场排位/巅峰，按对局ID去重；开房、匹配、娱乐、人机和未知模式排除。原始KDA不比较游走与打野。
- 各来源使用Beta(12,12)。近季最多75%、近期对局最多45%的样本可靠性权重覆盖旧估计；这两个混合依次进行。证据有效场次取各层最大值，避免把重叠对局误当多份独立证据。同英雄、同模式内重复记录去重。

当前战力锚点为0→0、500→15、1500→32、3000→50、5000→65、7500→78、10000→88、15000→96、20000→100，再乘0.1得到P。不是国标、市标、省标门槛，不做跨英雄排行百分位推断。

## 缺失、可信程度和偏好

目录覆盖较完整（该路至少65%的英雄有场次字段）但全部0场，属于可观察的低练习量；部分字段缺失、英雄列表未返回，则属于资料不足。后者不展示确定位置分，分队采用`账号指数-12`的保守补位先验。该先验是产品假设，不是已观测能力。本人校正仍明确列出。

“证据充分度”由账号证据、有效英雄样本、英雄池、当前战力和目录覆盖组合，范围0.1～0.88。它不代表统计置信概率。推荐分路与分数接近是可能的：均衡英雄池测试要求五路同分，不强行制造差异。多位置英雄平分曝光和英雄池，同时降低映射确定性；目前无法从累计英雄档案确认个人实际走位。

## 实际档案检查与回归

2026-10-16 本地QQ档案：对抗73.3、打野81.4、中路72.0、发育70.2、游走82.3；相较旧版0.4分的区间，新版约12.1分。当前可见近季游走主力为朵莉亚/桑启/瑶，中路主力小乔/大乔近期与生涯表现较弱。这里仅说明模型如何处理这份档案，不是已验证的真实对局能力排名。

微信档案的对抗与游走差异更明显；该账号场次更少，证据充分度同步降低。评分不因为模型能输出小数就宣称精确。

测试覆盖：专精位置优于很少练习的位置、均衡池不硬拉差距、当前战力贡献、历史最高战力不替代当前值、有/无巅峰参赛、旧峰值排除与衰减、小样本收缩、竞技/开房隔离、重复去重、近季英雄影响、多位置分摊、缺失与0场区分、偏好不伪造实力、校正上限及十人分队使用位置分。正式运行还需要积累更多真实分队反馈来校准权重。
